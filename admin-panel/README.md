# Quản trị cửa hàng

Trang quản trị React cho danh mục sản phẩm, sản phẩm, đơn hàng và nội dung cửa hàng.

## Chạy ứng dụng

```bash
npm install
npm start
```

## Dữ liệu Firebase

- `products`: sản phẩm, giá, tồn kho, ảnh và trạng thái kinh doanh.
- `categories`: danh mục sản phẩm.
- `orders`: đơn hàng và trạng thái xử lý.

Ứng dụng tiếp tục sử dụng cấu hình Firebase hiện tại trong `src/services/firebase.js`.
